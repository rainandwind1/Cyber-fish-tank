# 赛博鱼缸：初步游戏设计框架

> 版本：讨论稿 v0.1  
> 目标：先验证“搭出好看的缸，并把它养稳定”是否有趣；物种与水族知识采用可扩展数据表维护。

## 1. 一句话概念

一款轻松、可持续扩展的桌面鱼缸设计与养成游戏：玩家在不同室内空间里选择缸体，搭配设备、底床与造景，挑选适合的鱼和饵料，并用少量管理决策维持生态平衡；缸的外观和鱼群行为是主要回报。

## 2. 产品方向与首版建议

- **类型**：2D 俯视/侧视结合的鱼缸建造、轻模拟、收藏养成游戏。核心画面以鱼缸正面为主，管理面板尽量不遮挡观赏区域。
- **气质**：赛博朋克做“房间、UI、灯光和设备外观”的表达；鱼、植物和水体仍然自然、舒缓，避免所有东西都做成霓虹机械风。
- **首版美术建议**：采用精致像素风 2D。鱼缸是主要观赏对象，像素动画能以可控成本表现游动、觅食、躲藏、群游和昼夜变化；模块化家具、设备和造景也容易增量生产。优先做高辨识度的鱼剪影、有限但漂亮的水体光效，以及足够清晰的设备图标。
- **镜头建议**：房间用固定的 2D 侧视/轻透视场景，鱼缸正面展示；缸内以侧视空间呈现。先不做 3D 自由旋转和复杂建模。若后续想强化沉浸观赏，可再试验 2.5D 水体特效，不影响模拟层。
- **首版边界**：只做淡水缸；海水、繁殖育种、疾病诊断、真实品牌设备、多人分享、复杂经济系统放入后续候选。

## 3. 玩家核心循环

1. 选择房间位置和缸体规格，确认预算、承重/空间占用和可用设备空间。
2. 安装过滤、照明、温控等设备，铺设底床并布置硬景、植物和躲避空间。
3. 注水并启动设备，做水质准备和“开缸”阶段；水体稳定后再选择鱼。
4. 根据鱼的体型、群居需求、性情、活动水层和水质需求配置鱼群与饵料。
5. 观察鱼的行为和水质趋势，定期喂食、检测、换水、修剪植物、清理滤材或升级设备。
6. 获得审美评分、生态稳定度、鱼群状态和主题收藏进展，解锁新鱼、造景、房间和缸体。

**关键乐趣**：设计表达（我想做什么主题）＋搭配推理（怎样的设备和鱼能共存）＋观察回报（鱼会使用我布置的空间）＋长期养成（这缸逐渐稳定、长成自己的样子）。

## 4. 系统框架

### 4.1 缸体与空间

- 首批提供几种预设比例：小型桌面缸、标准长方缸、加宽缸、较高展示缸。尺寸、长宽高、容积和重量都显示出来。
- 建议首发用少量预设规格验证玩法；自定义尺寸作为后续功能。自定义时设置最小/最大长宽高、总容积上限、房间可用空间和家具承重上限，并用“可养物种/设备兼容性”反馈结果。
- 规格影响：可活动空间、鱼群容量建议、温度和水质变化速度、可安装设备档位、造景自由度、价格、重量和维护时间。
- 不建议使用简单的“每升可养几条鱼”作为唯一规则。游戏可用生物负荷、成鱼体型、鱼群最小数量、活动空间、性情和过滤能力一起判断，并给出可读的原因。

### 4.2 设备（以淡水缸为首发）

把设备做成可理解的类别和属性，而非堆很多同质商品。设备既解决生态问题，也带来噪声、耗电、空间占用、维护频率和外观差异。

| 类别 | 作用与可玩的属性 | 首版优先级 |
|---|---|---|
| 过滤器 | 机械过滤去除悬浮物；生物滤材为有益菌提供附着面；部分滤器兼有化学过滤。属性可包括适配容积、流量、过滤容量、噪音、占位、清理周期。类型：背挂、内置、海绵、桶式。 | 核心 |
| 加热器 / 温控器 / 温度计 | 适用于需要恒温的热带鱼缸；影响目标水温、温度稳定性、故障风险和安全性。温度计是监测工具，不等于加热设备。冷水鱼缸可不装加热器。 | 核心 |
| 灯具与定时器 | 提供观赏照明并支持水草生长；强度、光谱/色温、覆盖面积、亮灯时长影响植物状态、观赏效果和藻类压力。 | 核心 |
| 气泵、气管、气泡石 | 增加水面扰动和水体气体交换；有些过滤器本身也能带动水流，因此不必把气泵设计为每缸必装。属性：气流、噪声、耗电、气泡装饰效果。 | 核心（可选装） |
| 水质检测 | 检测氨/铵、亚硝酸盐、硝酸盐、pH；后续可扩展硬度、余氯等。测试盒/试纸/数字探头可有成本、精度、使用频率差异。 | 核心 |
| 水处理与换水工具 | 除氯剂/水质调理剂、虹吸管/底床清洁器、水桶、网兜、刮藻器、剪刀和镊子，支撑开缸及日常维护。 | 核心（工具简化） |
| 底床与滤材 | 砂、砾石、营养土；滤棉、生化滤材、活性炭等。影响植物、鱼类栖息、过滤效率和维护方式。 | 核心 |
| CO₂ 与水草系统 | CO₂钢瓶/扩散器、计泡器、阀门等提升水草造景上限，也增加成本与管理要求。 | 后续进阶 |
| 冷却与水流控制 | 风扇/冷水机、造浪泵/水泵/喷淋管等，服务高温环境或特定水流需求。 | 后续进阶 |
| 备用与安全设备 | 缸盖、防跳网、漏水警报、备用电源等，可作为高阶房间/突发事件系统。 | 后续 |

推荐首版的系统化简：以“过滤容量、温度稳定、光照强度与时长、氧气/水流、检测能力”几条可解释指标为核心。除非鱼种或造景需要，不要强制所有设备都装齐。

### 4.3 造景与水草

- 造景组件：底床、石材、沉木、洞穴/躲避物、背景板、前中后景水草、浮水植物、装饰件。
- 用前景/中景/后景和高度、色彩、疏密、留白等规则辅助布局；提供新手主题模板，也允许自由摆放。
- 造景不是纯装饰：躲藏点降低胆小鱼压力；开阔游泳区利于活跃鱼；水草影响遮蔽、观赏度、营养吸收与维护量；尖锐或不安全装饰可有风险提示。
- 可加入“水景构图”评分，但不把分数作为唯一目标；主题成就（雨林溪流、霓虹夜景、沉木森林、极简沙地）鼓励不同风格。

### 4.4 房间环境

- 首发环境：客厅、书房。差异先体现在美术、可放置空间、自然光、环境温度波动、噪音容忍度、家具承重与装饰主题。
- 房间物件可提供视觉装饰或小幅玩法修正，例如远离窗户减少日照藻类压力、靠近暖气导致温度波动、桌面位置限制缸体尺寸。
- 后续扩展卧室、工作室、阳台/温室等；阳台需要显著的温度和日照变化，建议作为挑战环境。

### 4.5 鱼种、群落与行为

每个物种用数据定义，而非散落在代码里的特殊判断：

- 成年体长、建议缸体尺寸、活动水层、游泳空间、群居数量、适宜温度/pH/硬度区间。
- 性情（温和/好斗/胆小）、捕食/被捕食倾向、混养兼容性、对水流/躲藏/植物的偏好。
- 食性（杂食/草食/肉食等）、饵料类型、喂食频率、残饵污染量、成鱼阶段变化。
- 状态：健康、饥饿、压力、活跃度；状态由水质、同伴、密度、环境、喂食和疾病风险共同影响。
- 行为动画：群游、巡游、觅食、躲藏、休息、争地盘、追逐等。首版实现少量行为但让差异明显。

首版鱼种可从容易识别、行为差异鲜明、适合入门淡水缸的少数物种里选（例如孔雀鱼、斑马鱼、斗鱼、鼠鱼等），每种都要先明确适配缸型与不能混养/不适合小缸的原因；不以“越多品种越好”为目标。

### 4.6 饵料与喂养

- 饵料维度：薄片、颗粒、沉底饵、冻干/冷冻活饵、藻类/植物性饵料。
- 按鱼种食性、口部/活动水层适配，选择喂食量和频率；喂少会饥饿，喂多会有残饵并加重水质负担。
- 可让玩家选择“手动喂食”观察互动或设定每日计划。首版避免复杂营养配方，把决策重点放在种类、份量、频率和残饵。

### 4.7 水质与生态模拟

首版建议模拟少数但互相影响的量：水温、氨/亚硝酸盐/硝酸盐、pH、溶氧（可抽象）、藻类/清洁度、过滤成熟度。核心过程是：鱼和残饵产生废物；成熟过滤系统中的有益菌逐步处理废物；换水和植物吸收帮助控制累积；喂养和鱼群规模增加负荷。

新缸需要经历过滤系统成熟的建立期。游戏中可以做成可视化进度和水质检测教学，而不是要求玩家等待现实中的数周。模拟重点是玩家能通过观察与检测理解原因，避免只显示“鱼不开心”的黑箱惩罚。

## 5. 进度、目标与可玩性补充

- **创作目标**：主题挑战、构图任务、限预算搭缸、特定鱼种友好缸。
- **生态目标**：稳定水质天数、降低维护成本、适合指定鱼群、保持植物健康。
- **收藏目标**：物种图鉴、设备外观、植物/硬景、房间装饰与赛博主题套装。
- **分享目标**：拍照模式、缸体快照、布局码/设计蓝图（后续再考虑在线社区）。
- **轻事件**：设备老化、停电、异常高温、鱼只生病等可选挑战；休闲模式可关闭或降低惩罚。
- **辅助体验**：新手推荐配置、兼容性提示、生态风险解释、可暂停/加速时间、离线时不惩罚玩家。

建议至少提供“自由观赏/创作模式”和“轻管理模式”两种预设，避免模拟深度把只想布景和看鱼的玩家挡在门外。

## 6. MVP（可试玩首版）

首版目标是验证搭建和养护是否形成有趣循环，推荐范围：

1. 一个客厅、一个书房，3 种预设缸体。
2. 6–8 种设备/底床核心件：过滤器（两型）、加热器、灯、可选气泵、基础测试工具、砂/砾石/水草底床。
3. 约 6 种硬景/植物、4 种鱼、3 类饵料。
4. 缸体摆放与造景编辑、放鱼/喂食/换水/水质检测操作。
5. 简化水质与鱼状态模拟、少数明确可见的鱼行为、基础教程和状态提示。
6. 一个自由创作模式和一条短目标任务线；暂不做大型商店经济、繁殖遗传或在线功能。

### 首版成功信号

- 玩家第一次摆缸后能说出设备和鱼选择为何合适。
- 玩家愿意反复调整构图，并能从鱼的行为看出空间和造景的影响。
- 维护操作有节奏但不变成每日打卡或惩罚性负担。
- 新增物种、设备和造景主要通过数据与素材扩展，不需要重做底层规则。

## 7. 风险与设计原则

- **物种准确性**：鱼类需求因品系、成长阶段和环境而异；用可信资料建立物种卡，避免把经验法则写成硬科学。所有建议可以呈现区间和风险等级。
- **过度复杂**：水质参数很多，首版只显示玩家能据此采取行动的少量指标；高级数据可渐进开放。
- **误导现实养鱼**：游戏会简化现实生态，物种卡和养护提示需区分“游戏规则”和“真实养护建议”；不要奖励拥挤、混养冲突或不合适的小缸饲养。
- **美术生产成本**：优先做模块化房间、设备、植物与鱼动画；少量鱼种要有可辨识行为，胜过大量静态鱼种。
- **闲置惩罚**：现实计时可以让玩家回来发现变化，但要避免离线死亡/损失；可以暂停模拟、采用短周期结算或在离线期间缓慢变化。

## 8. 建议的开发顺序

1. 先做一缸一房间的垂直切片：摆放设备和造景、放入两种鱼、查看水质/状态变化。
2. 打通“鱼种数据—兼容提示—水质负荷—鱼行为”的基础逻辑。
3. 补齐喂食、换水、成熟过滤、照明周期与首个目标任务。
4. 加入多种缸体、第二个房间、主题挑战和收藏解锁。
5. 再根据试玩反馈决定是否开发自定义尺寸、繁殖、经济系统、3D/2.5D或社区分享。
