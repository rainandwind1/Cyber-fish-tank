## 技术方向（暂定）

- 首选候选：Unity 6.3 LTS + URP + C# + Blender。
- 备选：Godot 4.7.2。
- 还未安装 Unity，也未最终锁定引擎；先做原型验证水体、鱼类游动、相机和摆放交互。
- 鱼在鱼缸三维空间内应使用自定义游动与避障逻辑，不直接套用地面 NavMesh。
- 水体优先使用实时材质/着色器等近似效果，不在首版做真实流体模拟。
- 用户电脑已有 Blender；此前建议安装 Unity Hub、Unity 6.3 LTS 和带 Unity 工作负载的 Visual Studio Community。
- 磁盘空间规划建议约 50–60 GB，实际用量以安装器显示为准。
